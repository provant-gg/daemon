● Builds clean. Here's what landed in daemon/main.go:

  - Connects to the Stats API socket (default 127.0.0.1:49123), reads NDJSON
  line-by-line.
  - Each line goes into a single events table: id, received_at (RFC3339Nano
  UTC), event_name (peeked from JSON, falls back to empty), raw_json (verbatim
  line).
  - Indexes on event_name and received_at so SELECT event_name, count(*) FROM 
  events GROUP BY 1 is instant.
  - Reconnects every 2s if the socket drops (game closes, between matches, etc.)
   — controlled by -reconnect.
  - WAL + synchronous=NORMAL so 30 Hz UpdateState writes don't bog down.
  - Pure-Go SQLite (modernc.org/sqlite), so it still respects the existing
  CGO_ENABLED=0 goreleaser config.

  Run it:
  cd daemon
  go run . -db events.db
  # then poke around:
  sqlite3 events.db "SELECT event_name, count(*) FROM events GROUP BY 1 ORDER BY
   2 DESC;"

  Note: heads-up — RL doesn't run on Linux natively, so this dies immediately on
   this box. Cross-build for Windows with GOOS=windows GOARCH=amd64 go build -o 
  rl-stats-daemon.exe . and run it on the gaming machine.

  - Detects arch via uname -m → maps to goreleaser's archive naming (x86_64,
  arm64, i386, armv6, armv7).
  - Picks tar.gz or zip based on OS.
  - Pulls from releases/latest/download/... (or pinned VERSION=).
  - Fetches checksums.txt, verifies SHA256 with sha256sum (Linux) or shasum -a 
  256 (macOS).
  - Installs to /usr/local/bin if writable, else ~/.local/bin (BIN_DIR
  overrides).
  - Warns if install dir isn't on PATH.
  - Uses curl if present, falls back to wget.

  daemon/README.md — one-liner:
  curl -fsSL https://raw.githubusercontent.com/provant-gg/daemon/main/install.sh
   | bash

  I went with curl over wget: macOS ships curl by default and not wget, and curl
   is in nearly every modern Linux base image. wget is more common only on
  minimal Debian-family setups.

  Windows users get a one-paragraph "grab the zip from releases" note —
  install.sh works under Git Bash/MSYS but native PowerShell users would need a
  .ps1 (let me know if you want one).

  The install command will only actually work after you push this repo to
  provant-gg/daemon and cut your first tag — at which point
  daemon/.github/workflows/release.yml builds the release that the script
  downloads.
